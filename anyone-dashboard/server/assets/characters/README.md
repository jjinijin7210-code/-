# 캐릭터 이미지 - Kokoro(こころ)

일본 심리학 채널의 공식 마스코트는 **Kokoro(こころ)** — 진희님이 만든 캐릭터 바이블
(Character Bible v1.0) 기준으로 확정함(2026-07-19). 흰색/크림색 둥근 블롭 모양 몸통,
검은 점 눈, 분홍 볼터치, 정수리에 민트그린 하트 더듬이가 특징.

현재 실제 표정 이미지 7장이 들어있어요(진희님이 "루나"를 통해 만들어서 전달, 2026-07-19):
`kokoro_neutral`(기본/웃음), `kokoro_angry`(화남), `kokoro_surprised`/`kokoro_surprised2`(놀람),
`kokoro_sad`(슬픔/울음), `kokoro_joy`(기쁨/환호), `kokoro_scared`(무서움/충격). 표정이 더 생기면
같은 방식(png/jpg, 배경 단순한 낱장 이미지)으로 이 폴더에 추가하면 돼요 - 코드 수정 없이
자동으로 인식됩니다.

이 폴더에 Kokoro의 실제 이미지(png/jpg, 표정/포즈별로 낱장)를 넣어두면, 심리학 유튜브 영상
자동 생성 시 AI로 새 이미지를 만드는 대신 이 캐릭터 이미지들을 그대로(부족하면 돌려가며) 써요.
캐릭터 바이블 시트 이미지 한 장을 통째로 넣는 게 아니라, 표정/포즈를 각각 낱장으로 잘라서
넣어야 실제 영상에 자연스럽게 쓰일 수 있어요.

폴더가 비어있으면 `psychologyVideoGenerator.js`의 KOKORO_CHARACTER_PROMPT 설명을 바탕으로
AI가 Kokoro와 최대한 비슷한 톤으로 새 이미지를 생성해요 - 완전히 똑같지는 않지만 에러는
안 나요. 실제 캐릭터 파일을 넣으면 그게 항상 우선순위가 높아요(더 정확하고 비용도 절감).

여러 장 넣어두면(예: 캐릭터가 여러 포즈/표정으로 있는 이미지들) 포인트마다 순서대로 돌려가며
씁니다. 세로(쇼츠)/가로(롱폼) 둘 다 쓸 거면 두 비율로 각각 준비해서 파일명에
`_vertical`/`_horizontal`처럼 구분해두면 나중에 비율별로 다르게 골라 쓰도록 연결할 수 있어요
(지금은 아직 비율 구분 없이 섞여서 쓰입니다).
