# 배경음악 (BGM)

이 폴더에 저작권 문제 없는(로열티 프리) mp3 파일을 넣어두면, 심리학 유튜브 영상 자동 생성 시
그중 하나를 랜덤으로 골라서 내레이션 아래에 아주 낮은 볼륨(15%)으로 깔아줘요.

파일이 하나도 없으면 그냥 배경음악 없이(내레이션만) 만들어져요 - 에러는 안 나요.

## 어디서 구하나요 (무료, 가입 불필요)

- YouTube 오디오 보관함(YouTube Studio > 오디오 보관함) - 유튜브 채널 계정으로 바로 다운로드 가능
- Pixabay Music (pixabay.com/music) - 가입 없이 다운로드 가능

"Calm", "Ambient", "Lo-fi" 같은 잔잔한 카테고리에서 몇 개 받아서 이 폴더에 mp3로 넣고 커밋/푸시하면 돼요.
