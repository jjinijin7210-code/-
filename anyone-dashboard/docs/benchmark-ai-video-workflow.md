# 벤치마킹 노트 — "AI가 만든 영상으로 월 1500 버는 개발자" (2026-07-30)

원본: https://youtu.be/N5sQSjNwgn4 ("다함께 잡잡잡" 채널, 출연자 개발남노씨, 25:45)
※ 실제 캡처 이미지는 저장 못 함(채팅에 인라인으로 붙여넣어져서 파일로 못 찾음). 텍스트 요약만 기록.

## 워크플로우 요약 (5단계)

1. **뜨는 유튜브 채널 찾기 (자체 제작 툴)**
   - YouTube Data API 키 등록 후 키워드/영상길이/국가언어/기간으로 채널 검색
   - "효율" = 조회수/구독자 비율로 랭킹 (구독자 263명인데 조회수 16.1만 → 효율 611.7배 같은 식)
   - 채널을 폴더(예: "경제학" 65개, "야담" 102개)로 묶어서 관리, 매일 아침 6시 자동 수집

2. **7단계 AI 영상 생성 위저드** (자체 제작 SaaS)
   - 대본 → 음성 → 스타일 → 스토리보드 → 이미지 → 영상 → 완성
   - 대본 작성 가이드: 문장 끝 마침표 후 띄어쓰기, 따옴표 금지(자막 지저분해짐/음성 변환 오류), 특수문자·이모지 금지, URL/이메일 직접 금지, **단어 뒤 괄호 금지** (예: "클로드(Claude)" X → "클로드" O — TTS/자막 오류 방지)
   - 스타일: 3D 애니메이션 / 조선시대 만화 / 포토리얼리스틱 / 빈티지 여행포스터 + 유저 커스텀 스타일(레고 미니피규어, 손그림 등)
   - 스토리보드: 대본을 자동 분석해서 씬 분할, 상단 타임라인에 "후킹" 구간을 명시적으로 태깅(예: 0:00~3:15), 씬마다 상세 이미지 생성 프롬프트 자동 작성
   - 완성 단계: **CapCut 프로젝트(zip)로 export** — 오디오(mp3), 자막(srt), 스토리보드, 이미지 포함. 완전 자동 렌더링이 아니라 CapCut에서 사람이 마지막 편집
   - 자막 싱크 안 맞을 때 "싱크 재시도" 기능 있음 (무료 횟수 제한)

3. **CapCut에서 최종 마무리**
   - export된 프로젝트를 CapCut에서 열어서 미디어 연결 후 편집 완료

4. **경제채널 14개 벤치마킹 데이터 리포트** (별도 분석 문서)
   - 최근 2주 업로드 롱폼 318개 전수 분석, 채널 A~N 익명화
   - 결론 5가지:
     1. 구독자는 의미 없다 (신규 채널도 알고리즘 추천으로 바로 중간값 냄)
     2. 전체 조회수 68%를 상위 14% 영상(46개)이 만들고, 61%를 상위 5개 채널이 만듦
     3. 안정성의 원천은 물량이 아니라 "소재 축 + 템플릿 고정"
     4. 소재의 본질은 정보가 아니라 감정 — 소재에도 수급(공급 과잉/부족)이 있음
     5. "길수록 잘 나온다"는 절반만 사실 (서사력이 원인, 길이 자체는 아님)
   - 채널별 썸네일/톤 패턴 예시: "실사·AI합성 위기장면+하단 2줄", "AI 밈 캐릭터+만화식 과장", "감성 실사+OO의 몰락 시리즈"

5. **썸네일 제작 2단계**
   - 베이스 이미지: Gemini(제미나이)에서 생성
   - 텍스트 오버레이: 미리캔버스류 템플릿 툴에 "문구 입력" 플레이스홀더 + 화살표 + 색상 원 패턴
