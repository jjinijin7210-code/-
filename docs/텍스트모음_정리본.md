## 1. 음악 · 플레이리스트 채널 (가장 큰 덩어리)

### 1-1. 기획: 타겟과 니치부터
- 타겟을 먼저 정합니다. 누가 듣는지, 언제 듣는지, 왜 듣는지를 정하고, 내 음악이 어떤 상황에서 어떤 역할을 하는지를 생각합니다. [유튜브음악으로 살아남기]
- 플레이리스트 타겟은 만 25~35세입니다. 장르별 청취 장소와 시간대를 나눕니다. [음악 플레이리스트로 부업하기]
  - 힙합·인디·R&B는 이동 중(오전·밤)
  - 댄스·아이돌은 팬덤
  - 발라드는 한글 가사가 중요
  - 아이유는 40대까지 인기, 청취 시간은 20대가 가장 높음
  - 인구는 50~60대 이상이 많고, 20~30대는 6~8시에 시청이 많음
- 가사 없는 음악을 만들 때는 키워드에 `no vocals`를 반드시 넣습니다. [유튜브음악으로 살아남기]
- 쉽다고 막 찍어내면 안 되고, 내 가치를 넣어서 사람 냄새가 나야 합니다. [유튜브음악으로 살아남기]
- 고단가 니치는 [1-8](#1-8-고단가-니치-아이디어)에서 따로 정리했습니다.

### 1-2. AI 음악 만들기: 프롬프트 공식
**GPT/Gemini에 먼저 가르칠 것** [유튜브음악으로 살아남기, 음악 플레이리스트로 부업하기]
1. 정확한 장르 / 메인 악기 / 감정선 / 다이나믹(높낮이)
2. 실제로 유명했던 곡의 구성을 레퍼런스로 삼기
3. 긴장과 이완을 명확하게 (섹션별로 강도를 숫자로 표기)
4. 멜로디가 쉴 수 있게 가사량 조절, AI 같은 워딩(네온·멜로디·계절 등 뻔하거나 음악을 직접 언급하는 말) 금지
5. 장르 특성은 추측하지 말고 검색해서 반영

**딥하우스 인스트루멘털 구조 규칙** [유튜브음악으로 살아남기]
- Genre & Subgenre: 장르를 구체적으로
- Mood & Energy: 감각적인 공간 묘사 포함
- Instrumentation: 악기명과 음색 성격까지
- Production Quality: BPM, 키, 박자, no vocals, 곡 마무리 방향
- 예: 딥하우스 인스트루멘털, 라운지 바 저녁 조명, 위스키 한 잔 느낌, 120~122 BPM, "옵션 3가지로 줘"

**K-POP 작사 프롬프트 요지** [음악 플레이리스트로 부업하기]
- 역할: "상업 K-POP 탑라이너 디렉터"
- 후렴은 "짧은 반복 Hook → 의미 확장" 패턴을 1마디 단위로 반복
- verse는 리듬 중심, pre-chorus는 점진적 상승(가사량 감소), chorus는 발음이 쉽고 반복적
- 한국어 70~80%에 영어 20~30%, 길이 2~5분
- 완전히 새로운 곡이어야 하며 표절 금지. Suno가 인식하도록 섹션 태그를 명확히 쓰고, 가사는 한 번에 복사할 수 있게 작성
- 전체 흐름은 점진적으로 고조되고 후렴에서 최대 해방감을 줌

**글로벌 플레이리스트용 작사 프롬프트** [음악 플레이리스트로 부업하기]
- 장르는 그루비 팝, 영어·한국어 혼용, 타겟은 전 세계 청취자
- 목표는 4분 이상 반복 청취용 배경음악, 감정은 보편적이고 명확하게
- 첫 소절은 후렴으로 시작(강한 후킹), 후렴은 중독적·감정적·서사적으로 다양하게

**제목 대량 생성** [음악 플레이리스트로 부업하기]
- Gemini에 "사랑의 이별 아픔 이야기를 영어 제목·한글 제목·한글 주제로 테이블 60개, 제목은 세련되게"를 요청하고, 별로면 더 좋게 다시 시킵니다.
- 엑셀에 붙여서 보관하고, 엑셀과 연동되는 '메이크' 자동화나 '플리메이커'(자동 모드)를 쓰면 대량 생산이 됩니다. 수동은 Suno.

**지침서 만들기** [음악 플레이리스트로 부업하기, 프롬프트~영상까지 만들기]
- 노트북LM에서 새 노트 → Deep research로 "Suno AI 프롬프트 엔지니어링" 조사 → 가져오기 → "수노 AI 작사/작곡 가이드 생성" → PDF·워드로 보관
- 김이나 작사법을 노트북LM에서 따로 조사한 뒤, "너는 김이나 작사가이자 Suno 프롬프트 엔지니어야. 김이나 스타일로 작사·작곡하고 왜 그렇게 했는지 설명해줘"라고 시킵니다.
- ChatGPT 지침서는 새 프로젝트에 이름을 붙여 이어서 쓰면 누적되어 좋습니다.
- 잘되는 채널(예: 고스타그램)의 링크와 지침서를 Gemini에 넣고 "노래 스타일은 유지하고 가사만 바꿔줘"를 요청한 뒤 Suno로 갑니다.

### 1-3. Suno 사용법
- **Custom Model**: 내가 아는 깨끗한 음원 약 6곡으로 학습시키면 결과가 좋습니다.
- **수정 방식**: 통째로 100번 뽑지 말고, 80점짜리 인스트를 뽑아 보컬을 얹고 어색한 부분만 인페이팅해서 다듬는 편이 압도적으로 효율적입니다.
- **입력 영역**: 사운드 지정 영역(장르·보컬·분위기·악기·BPM·프로덕션, 짧고 명확하게)과 가사·서사 영역(주제, 메타태그). Simple 모드는 사운드 영역, 어드밴스드 모드는 가사·서사 영역입니다.
- **태그 사전**
  - 구조: `[Intro] [Verse] [Pre-Chorus] [Chorus] [Bridge] [Refrain] [Hook] [Outro]`
  - 연주·효과음: `[Guitar Solo] [Drum Roll] [Break]/[Stop] [Piano Interlude] [Drop]` (악기명을 명시하면 인식률이 가장 높음)
  - 보컬·코러스: `[Acapella] [Scream] [Cheering] [Whisper] [Ad-lib]`, 소괄호 `( )`는 백업 보컬
  - 역할 분배: `[Male Vocal] [Female Vocal] [Rap] [All]/[Chorus Voicing]`
  - 듀엣곡 전체 구성 예시가 있음: Intro → Verse 1(남/녀) → Pre-Chorus → Chorus → Verse 2(랩) → Bridge → Break → Acapella → Drop → 최종 Chorus → Outro(Fade out)
- **간단 입력 공식**: "○○○○ 느낌의 Suno용 음악 스타일·가사를 만들어줘. 가사에는 △△ 태그를 필요한 만큼 자연스럽게 넣어줘". ○○에는 아래 4가지 중 하나를 넣고, △△에는 원하는 태그 종류를 넣습니다. [음악 플레이리스트로 부업하기]
  1. 참고 MP3와 비슷한 분위기
  2. 특정 가수·곡 느낌 (예: 뉴진스 Ditto처럼 아련하면서 비트감)
  3. 감정·상황 키워드
  4. 글·텍스트 분위기

### 1-4. Lyria 3 (Gemini 음악 생성) 흐름 [일본음악으로 부업하기, 프롬프트~영상까지]
1. Claude에 잘되는 일본 플레이리스트 채널 링크를 넣고, "벤치마킹해서 나도 이렇게 될 수 있게 A~Z 전략과 실행 액션플랜을 제시해줘"라고 요청
2. "분석한 내용을 토대로 Lyria 3로 3분짜리 음악을 만들 명령어를 줘"라고 요청
3. Gemini `+` → 음악 만들기 → Lyria 3 → 3.1 Pro(사고 모드) → 핵심 원칙 명령어를 넣고 "3분 내외로" 요청
4. 생성하는 동안 구글비즈로 썸네일을 넣고 "이미지 루프 영상 + 음악 파동"을 만듦
5. 캡컷에서 영상과 음악을 합쳐 편집
- 고르기 힘들 때: "나는 잘 모르겠으니 조회수가 폭발할 수 있는 걸로 다 알려줘". "음악은 생성하지 말고 대화만 하자"고 한 뒤, 추천 중 하나를 골라 "( )번을 Lyria 3로 만들 프롬프트를 먼저 뽑아줘"라고 합니다.
- 일본어 플레이리스트 검색어: プレイリスト / 歌單 / Playlist, 인기순으로 정렬
- 클래식은 "100년이 지나 저작권이 없다"는 이유로 채널 소재가 됩니다. (단, 음원(녹음) 권리는 별개일 수 있어 [8장](#8-리스크--기존-원칙과-충돌하는-부분)에 따로 표시했습니다.)

- 영상: 구글 플로우/Grok으로 VEO 루프 영상을 만듭니다. "모닥불만 움직이고 카메라는 고정, 아주 슬로 모션으로 천천히 줌 아웃"이라고 요청하고, 두 번째는 "카메라를 절대 움직이지 말고 중앙 모닥불에서 연기만 조금씩 나게" 요청합니다. 캡컷에서 속도를 줄이고 영상 본연의 소리는 제거한 뒤 복사 붙여넣기와 역방향 재생으로 길이를 늘립니다. 제목 텍스트(COZY CAMPFIRE ASMR)는 애니메이션으로 넣고 스틸 프레임을 이미지로 내보내 썸네일로 씁니다.
- 음악 보정: BandLab → import audio → Fx → 그래픽 EQ(5dB 이하) → 마스터링

**한복 입은 외국인이 트로트 부르는 쇼츠** [음악 플레이리스트로 부업하기]
- 조회수가 잘 나오는 소재입니다. Gemini로 "금발의 외국인 여성이 한복을 입고 무대에서 노래하는 이미지, 전신, 9:16"을 만들고, "찻집의 고독" 스타일(목소리 위주) 음악을 만든 뒤 캡컷에서 AI 대화 장면(캐릭터 사진 업로드 + 오디오 추가)으로 완성합니다.

**힙합 로파이 앨범 발매 방식으로 운영하기** [k-pop 아이돌 컨셉 이미지만들기]
- 발매 자료를 유튜브 요소와 대응시킵니다: 아티스트명=채널명, 앨범명=영상 제목, 곡 제목=영상 챕터, 음원 파일=영상, 앨범 커버=썸네일, 텍스트 파일=자막, 소개글(크레딧)=설명글
- 앨범 커버는 3000×3000

### 1-6. 음악 비주얼: 앨범 커버 · 썸네일 · 루프 영상
- K-POP 앨범 커버 스타일 컨셉 이미지: 얼굴 라인을 살짝 더 V라인으로 하고, 컨셉별로 티저 포토 스타일을 달리합니다. 예: Golden Letters(금빛 편지·햇살), Slow Sunday(카페·책·니트), 빗속의 문장(비 오는 창가·우산), 달빛의 꿈(블루톤), 별빛 아래 잠들다(드림팝) [k-pop 아이돌 컨셉 이미지만들기]
- 핀터레스트에서 "summer" 등으로 배경 사진을 받아 Gemini에서 약간 변형해서 씁니다. [음악 플레이리스트로 부업하기]
- 유튜브에서 rain 검색 → 필터 → 크리에이티브 커먼즈(CC) 영상 몇 개를 스크린샷으로 GPT에 주고 썸네일을 만들어달라고 합니다. [모닥불 ASMR]
- 일본 타겟 썸네일은 표본 썸네일을 ChatGPT에 넣고 "이 느낌으로 3가지 버전"을 요청합니다. [일본음악으로 부업하기]
- 이미지 루프 영상: 구글비즈에 썸네일을 넣고 "이미지 루프 영상 + 음악 파동"을 요청합니다.
- 이미지로 영상을 만들 때는 먼저 프레임을 쪼갭니다. `프레임을 분해해서 각 프레임을 별도로 이미지로 제작해줘. 1프레임당 한 장씩` → `이제 다음 시나리오를 고려해서, 각 이미지를 첫 프레임으로 하여 영상화해줘` [유튜브음악으로 살아남기, 7초영상 쇼츠]

### 1-7. 유통 · 음질 · 저작권
- **배급사 등록**: DistroKid(20곳 이상 스트리밍), 디토뮤직 등. 외국 업체는 대처가 늦음. 국내는 수익이 나면 15~20% 수수료를 떼며 멜론·지니·벅스로 발매. [모닥불 ASMR, k-pop 아이돌]
- **유통사 서칭과 반려 대비**: WAV/MP3, 44.1kHz/16-bit(CD 규격) 또는 48kHz/24-bit(방송·영상 표준). True Peak −1.0~−2.0 dBTP, 통합 음량 −14~−9 LUFS. 정규 앨범 정도로 곡 수를 늘리고, 곡당 3분 이상. [k-pop 아이돌 컨셉 이미지만들기]
- **기성곡을 저작권 문제 없이 쇼츠에 쓰는 방식**: 원 영상의 음원을 받아 캡컷에서 이미지와 함께 편집한 뒤, 쇼츠 등록 화면에서 "사운드 추가"로 해당 영상의 음악을 검색해 출처를 남깁니다(뮤직 피커: 유튜브에서 음원을 올려야 저작권에서 자유로움). [음악 플레이리스트로 부업하기]
- 기타 키워드만 적힌 항목: 매직 라이트(영상), 믹스테이프, amuse/mexni, 자장가, AI 플레이리스트 크리에이터, API 키, 구글 위스크

### 1-8. 고단가 니치 아이디어 [k-pop 아이돌 컨셉 이미지만들기, 벤치마킹=니치밴딩]
- **수면용 게임 영상(90분)**: 차분한 긴 대본 + 게임 화면을 직접 녹화(OBS 무료) + 잔잔한 나레이션
- **숨겨진 역사·미스터리**: Perplexity로 리서치 → Claude로 대본 → 이미지·영상 AI(클링/런웨이/노트북LM)로 움직이기. 교육자료가 아니라 영화처럼, 연도 암기가 아니라 감정·긴장·반전을 넣고 "영화 예고편처럼 써줘". 조선시대·근현대사 미스터리와 비하인드(40·50대 픽).
- **부자 채널**: 요트·제트기·골프·수입차·부동산·자산관리. 무료 럭셔리 푸티지에 고급 나레이션을 얹는 구조로, 승부는 말투(전문적인 목소리).
- **심해생물**: Perplexity로 리서치 → 이미지 AI로 보충 → 으스스한 음악 + 줌인. 우주·동물로 확장.
- **인프라(다리·터널)**: 해외에서 잘 터집니다. 지루한 소재에 긴장감을 입히고, 한국은 GTX·해저터널·신공항 같은 메가 프로젝트가 소재.
- **벤치마킹 = 니치 밴딩**: 브이로그(과거 시점), 운동 채널(효율적인 운동), 인물 일대기(유통기한 없는 콘텐츠), 반려동물 행동심리, 다이어트·육아용품. 잘된 영상의 구조를 분석해서 적용합니다. 방법은 Gemini에 유튜브 링크를 넣고 "이 영상처럼 만들고 싶으니 분석해서 Google VEO3에 넣을 장면별 프롬프트를 만들어줘. 장면 설명·카메라 앵글·인물 표정과 동작·대사·길이를 포함해 바로 복사 붙여넣기 되게"라고 요청합니다.

## 2. 영상 제작 방식 (도구별 레시피)

### 2-1. 이미지 → 영상 루프 / 스토리북 영상
**스토리북 영상** [스토리 북으로 유튜브 하기]
1. Gemini → Gem → 스토리북 만들기 → 남·여 주인공 사진 첨부 → "서울 배경 로맨스, 일본 애니메이션 스타일, 20대 이상 성인 대상"
2. 완성된 10장을 `001.png ~ 010.png`로 다운로드
3. 새 채팅에 10장을 넣고 "스토리 나레이션을 위해 각 이미지에 어울리는 문장을 한 줄씩"(사고 모드) → TTS로 보낼 텍스트만 추출
4. "Generate Speech" → Single-speaker audio → Voice(Zephyr) → 붙여넣고 Run → WAV로 다운로드. 남·여 목소리를 다르게 받을 수 있음.
5. Grok → Imagine → 이미지 업로드 → "6초 길이의 완전한 무한 루프 영상. 첫·끝 프레임이 업로드한 이미지와 동일, 카메라 고정, 조명·색감 일관, 시작 프레임으로 돌아오는 순환형 움직임, No music" → 업스케일 → 다운로드
6. 10장 반복 후 캡컷에서 이어 붙이기

**40개 키프레임 애니메이션** [60대이상 시니어 영상 만들기 후반부]
1. Gemini에서 "신분의 격차·계약 연애 같은 K드라마 클리셰 스토리 3000자 이상" 작성 → 캐릭터 시트(외모 묘사) 작성 → 저장
2. 노트북LM 새 노트 → 스토리와 캐릭터 시트 업로드 → "40개 키프레임 이미지 프롬프트 작성" → Save to note → Convert to source
3. "1번~20번 프롬프트를 슬라이드로 시각화(텍스트 없음, 일본 애니메이션 스타일)" → 21~40 반복 → 슬라이드별 수정은 Revise
4. 나레이션: 키프레임별 해설자·등장인물 대사를 작성해 메모장에 저장 → Generate Speech(Single speaker, 보이스 Aoede)
5. 40장을 구글 플로우나 클링에 넣어 대사를 넣고 영상 제작 → 캡컷

**역사·다큐 (You are History 벤치마킹)** [60대이상 시니어 영상 만들기 말미]
- 조회수가 나온 외국 채널 링크를 Gemini에 넣고 분석하게 합니다. 구조 해부 프롬프트를 노트북LM에 넣고 Deep research로 "같은 제목 형식·대본 구조의 새 에피소드 바이럴 제목 5개"를 뽑고, 하나를 고르면 전체 대본을 씁니다.
- 대본 구성은 초반 30초 후킹 + 중간중간 휴먼 터치 + 마지막 솔루션입니다.

### 2-2. 구글 플로우 · 옴니 · 비즈 · VEO [플로우 영상만들기, 사진4장으로 수익, 7초영상]
- **Gemini 옴니**: 영상 만들기에서 템플릿을 써서 최대 10초까지 만들 수 있고, 유료 구독이 필요합니다.
- **구독·좋아요·알림 인트로** 프롬프트 예: "구독"은 핑크 네온, "좋아요"는 노란 3D 말랑한 클레이메이션, "알림설정"은 만화책 POW 효과. 어두운 미니멀 모션그래픽 배경, 시네마틱 조명, 4K.
- 교육용 프롬프트 예: 점토 씨앗이 자라는 과정을 스톱모션 느낌으로(손은 나오지 않게). 음악에 반응하는 영상 예: 피아노 선율에 맞춰 조명이 밝아짐.
- **플로우 에이전트**에서 에이전트를 옴니로 설정하면 배경·분위기를 일부만 바꿀 수 있습니다. 같은 영상에서도 숲속·우주·홀로그램 스타일 등으로 연달아 변환할 수 있습니다.
- **영상 합성**: "입력 비디오의 포즈와 동작을 이 이미지의 캐릭터에 적용"하는 지시를 씁니다. 자료 영상 1개와 이미지 5개를 넣었더니 하루 일과 영상이 완성됐습니다. 스토리보드를 첨부하면 그 순서대로 모션을 넣을 수 있습니다.
- **구글비즈 + Veo 3.1 파이프라인**:
  1. 스토리: Gemini로 시나리오와 모델 시트 작성(여러 표정이 나오는지 확인 필수)
  2. 이미지: 구글 플로우 + 나노바나나2로 장면 컷 생성
  3. 영상: 비즈에서 Veo로, 장면 행동 프롬프트를 이미지 설명에 넣어 생성
  4. 음성: 나레이션은 5~6초로 짧게(빈 화면 방지) → 목소리 선택 → 음성 해설
  5. 음악·자막: Lyria 3(30초면 무료, 전체는 유료) → 모든 오디오에 적용 → 자동 자막
  6. 마무리: 장면 전환 효과(0.4초쯤) → MP4 다운로드
- 시댄스 2.0 [인스타로 부업하기]: "콘티로 시댄스 2.0 영상 만들어줘. 15초, 720p, BGM 없이. 주인공과 할머니, 제품, 배경 모두 포함". 엘리먼트 락이 필요하고, 15초짜리 4개를 이어 붙여 만듭니다(드리미나 툴).
- 한 번에 이미지를 영상화하는 일반 요령: ChatGPT로 이미지를 먼저 만들고, 몇 컷을 만들지 먼저 정합니다.

### 2-3. 캐릭터 일관성 · 아바타
- **레퍼런스 CHR(고정 명령어)**: 사람 얼굴 등을 동일하게 이어주는 고정 명령어를 만들고, ChatGPT에서 인물(정면·측면·뒤·전체)을 각각 만든 뒤 배경 프롬프트도 따로 만듭니다. 이름과 함께 첨부해야 하므로 꼭 같이 저장하고, 시댄스 AI에서 씬마다 필요한 인물 사진을 넣습니다. [막장드라마로 유튜브하기]
- **마스터 캐릭터**: 원하는 이미지를 Gemini에 넣고 "똑같이 하지 말고 다른 스타일로 전면·후면·측면·전신이 나오는 마스터 캐릭터"를 만들어, 그 캐릭터로 스토리보드 "Detailed Image Prompt"만 출력합니다(장면 번호 없이 장면 사이는 줄바꿈 두 번). [유튜브 AI 심리학 자기계발]
- **시니어 영상 아바타**: 원본 영상의 전문가 모습을 ChatGPT에 넣어 "정면을 보는 이미지로 프롬프트화"(정면이 신뢰감을 줌) → 플로우(나노바나나2, 16:9) 이미지 생성 → 같은 곳에서 영상으로 변경. 영상 지시: "이 사람이 정면을 보며 조용히 말한다. 카메라 고정, 앵글 고정, 줌 없음, 고개 숙임 없음". [60대이상 시니어 영상 만들기]
- 아바타를 쓰는 이유: 검열에서 비교적 자유롭고, 실제 사람이 말하는지 비교할 수 없기 때문입니다. 이 노트에는 "AI 영상이라는 내용을 반드시 입력"하라는 말도 같이 적혀 있습니다.

### 2-4. 코드로 영상 만들기 (Remotion)

## 3. 숏폼 · 롱폼 콘텐츠 유형별 방식

### 3-1. 쇼핑 쇼츠 [쇼핑 쇼츠 노트, 사진4장으로 수익을 올릴수 있는데, 크몽 디자인 판매]
**대본 공식**: 후킹 → 문제 제기 → 공감 → 해결 → CTA. 영상 시작 때 눈에 띄는 것이 후킹이므로 앞쪽에 둡니다.

**상품·소스 찾기**
- 아이템스카우트 → 아이템 발굴 → 카테고리 → 주제별·트렌드 키워드 → 신규 키워드(7일·한 달) · 급상승 키워드. 사람들이 좋아하고 클릭률이 높은 것을 고릅니다.
- 쇼핑몰: 올리브영, 지그재그, 쿠팡, 알리익스프레스, 네이버. 인테리어·패션·요리는 샤오홍슈, 그 외는 도우인.
- 테무 베스트셀러를 먼저 검색하고, 쿠팡에 있는지 이미지로 확인합니다(테무 이미지 1장을 구글 이미지 검색에 업로드). 영상 1개당 상품 링크 3~4개를 추가로 겁니다.
- 인스타 → 화면 우클릭 → 구글 렌즈 → 캡처 → 쿠팡 확인 → Gemini에 "이거 찾으려는데 중국어·영어 키워드를 알려줘" → 틱톡 검색. 원본 영상 검색 제시어는 중국어 10개, 영어 10개를 만듭니다.
- 영문명은 GPT에게 물어서 영상을 찾습니다.
- 틱톡 영상은 링크를 ChatGPT에서 `shorts → video`로 바꾸고 스크립트를 추출한 뒤, "저작권 문제없이 우리만의 대본 스타일로 길이는 유지"하게 바꿉니다. [크몽 디자인 판매]

**대본·음성·편집**
- ChatGPT에 "너는 제품 리뷰 콘텐츠 전문가야. 설명을 바탕으로 15~20초 쇼핑 제품 리뷰 대본을 간결하고 설득력 있게 작성"이라고 역할을 주고, 상품 제목과 리뷰를 "~라는데" 말투로 넣어서 다듬습니다. 대본을 가져올 때는 "저작권에 걸리지 않도록 구조는 그대로, 문장은 바꿔줘"를 쓰기도 합니다. 소구점 1·2·3을 찾아 대본을 쓰고, 내가 직접 더빙(구글 스튜디오)하거나 타입캐스트(10배 자연스러운 목소리)를 씁니다.
- 영상 마지막 자막과 목소리: "해당 상품과 정보가 궁금하시다면 프로필에 있는 링크를 눌러주세요"
- 영상 소스 3~5개를 폴더에 정리하고 자막 제거 툴(vmake)로 지워진 부분만 쓰며, 이탈 방지를 위해 겹쳐서 진행합니다.
- 캡컷: 음성 보정 → 노이즈 제거 → 볼륨 +10, 자막은 자동 캡션, 장면 분할 후 영상 소리는 끄기, 자막 구간을 가까이 붙이기(깜빡이면 시청에 방해).
- **광고 표기 필수**: 기본 텍스트(광고)를 영상 상단 오른쪽에 넣습니다. [사진4장으로 수익을 올릴수 있는데]

**인포크링크로 쿠팡 링크 걸기** [인포크링크 하는법]
1. 인포크링크 가입 → 채널 ID 입력(변경 어려움)
2. 왼쪽 링크 → 주황색 `+` → 링크 버튼 → 연결할 주소에 쿠팡 상품 링크 → 타이틀에 제품명(제품 순번 필수) → 이미지에 제품 썸네일 → 링크 복사
3. 유튜브 채널 → 채널 맞춤 설정 → 링크에 제목 "인포크링크"와 복사한 링크 입력

**연예인 추천템 쇼핑 쇼츠** [연예인 쇼핑쇼츠]
- 출처를 꼭 넣고, 출처로 들어가서 영상을 더 보도록 홍보도 합니다.
- 연예인 채널 영상의 더보기 → 질문하기 칸에 상품을 검색하면 타임라인이 나오고, 그 구간만 20초 내외 쇼츠로 편집합니다.
- 썸네일은 처음 영상과 스크린샷을 Gemini에 넣고 "레퍼런스 기반 썸네일 제목 10개"를 요청합니다.

### 3-2. 레시피 쇼츠 [레시피 쇼츠]
- 대본 문의 예시: "탄수화물을 먹으면 혈당이 확 올랐다 뚝 떨어져서 아이 집중력이 바닥을 친다… 밀가루·설탕 1도 안 들어가는데 단백질은 빵빵… 우리 아이 똑똑해지는 초간단 레시피 궁금하면 '똑똑' 남겨주세요"
- 이 문체로 "곰돌이 케이크, 가지 버전"처럼 비슷하게 만들어달라고 요청합니다. "똑똑 남겨주세요"는 댓글 키워드 트리거 CTA 방식이라 애니원 CS 트리거(§7)와 같은 구조입니다.

### 3-3. 해외 영상 → 일본·스페인 쇼츠 [7초영상 쇼츠, 가십 라운지, 해외 영상으로 일본 유튜브 하기]
**소재 찾기**
- 미국 유튜브 접속: `www.youtube.com/feed/trending?gl=US` 또는 프로필 → 설정 → 위치 → 미국
- 해시태그(`#이름`)로 검색하면 쇼츠만 볼 수 있습니다. 조회수 높은 영상의 인기 댓글에서 공감 포인트를 찾습니다.
- 유튜브는 경제 수준에 따라 단가가 다르므로 일본·미국 시청자를 노립니다. 남들이 모르는 예능이 좋고, 예시는 넷플릭스 "요알못", 친자 찾는 프로그램, 프랭크 판사, 투자예능(샤크탱크), 독일 게임 상금 예능, 고든 램지, 아메리칸 갓 탤런트 등입니다.
- 데이터로 확인: 주제를 검색해 관련 쇼츠가 많고 지금도 잘 나오는지 봅니다. 쇼츠 관련 영상이 많으면 "안 잡는" 확률이 높다는 메모가 있습니다.
- 매일 터진 영상 소재를 확인하고 원본을 찾습니다(크롬 구글 렌즈로 이미지 검색). 더우인(샤오홍슈) 영상은 공유 링크를 복사해 더우인 다운로드 사이트에 넣어 받습니다.

**제목·대본**
- Genspark AI 워크스페이스 4.0에 "쇼츠로 각색할 건데 댓글 인기순을 참고해 제목을 센스 있게"라고 요청합니다. 입력 항목은 ① 제목 요청 ② 카테고리(피아노·동물 종류 등) ③ 링크 ④ 링크의 좋아요 많은 댓글이고, 조건은 위트 있게·공감 가게·조회수 기반·한글로입니다.
- 최종 제목으로 인트로 멘트("~라는데" 말투)와 대본을 만들고, 어색한 부분은 고칩니다. 링크 영상을 참고해 대본이 들어갈 장면을 맞추고 SRT 파일로 받습니다.
- 캡컷: 검은 화면 → 제목 텍스트 → SRT 가져오기 → 유튜브 쇼츠 비율 → 폰트(아네모네체) → 텍스트를 음성으로(1.4배속) 또는 타입캐스트(유료) → 텍스트에 포인트 색.
- 번역해서 일본어·스페인어로 올립니다. 일본어는 띄어쓰기가 없고 마음대로 줄바꿈하면 오해가 생깁니다. 일본어 목소리는 보이스 복스(크롬 확장프로그램)로 만들고, 자막은 크롬에서 받을 수 있습니다.

**일본 가십 라운지 채널** [ゴシップ・ラウンジ]
- 미국 방송을 보고 쇼츠를 만들어 일본에 수출합니다(감동 소재를 좋아함). 소재는 스크럽 대디, 소피 파워스, 고든 램지 등이며, 일본인은 팝스타와 할리우드 배우 가십에 반응이 빠릅니다.
- 제목 공식: `【자극 키워드】 + 핵심 내용 + 후킹 문구`. 키워드는 【衝撃】(충격), 【泥沼】(막장), 【光と影】(빛과 그림자), 【裏事情】(비하인드). 예: 【衝撃】テイラー・スウィフトの総資産がヤバすぎる…
- 채널 이미지: 퍼플/블랙 네온이나 골드/블랙의 바·라운지 느낌. 자막은 깔끔한 고딕에 노랑/검정 테두리.
- 채널명은 직관적이어야 합니다(예: 海外セレブのリアル). 쇼츠는 1~2초 만에 이탈하고, 알고리즘이 채널명·제목·자막 키워드로 시청자를 찾기 때문입니다.

### 3-4. 드라마 · 막장 · 스토리북 · 숏드라마
- **막장 드라마 유튜브**: 유튜브에서 "인생사연" 검색 → Gemini에 "영상 분석해줘" → 레퍼런스 CHR → 프롬프트 → 인물 이미지 → 시댄스 AI로 씬별 영상 → 캡컷 편집 [막장드라마로 유튜브하기]
- **드라마로 60초 쇼츠**: 네이버·넷플릭스 1~10위 작품(영화, 일일드라마 가능)에서 연기 중 재미있는 부분을 골라, 한 편에서 4~5개를 만듭니다. 예고편은 써도 괜찮고, 처음 3초는 후킹, 그다음은 기승전으로 짜깁기합니다. 저작권이 있어 조심해야 한다고 메모되어 있습니다. [드라마로 60초 쇼츠]
- **뉴스 쇼츠**: 네이버 기사 → GPT 뉴스쇼츠 작가에 원문 붙여넣기 → 대본 → TTS 타입캐스트(유료) → 유튜브에 있는 영상을 가져와 캡컷 [스토리 북으로 유튜브 하기 말미]
- **정치 영상**: KTV 영상 위주로 보고 초반이나 후반에 내 생각을 넣습니다. 유튜브 영상의 Gemini 요약으로 몇 분 몇 초쯤 나왔는지 알 수 있고, 캡컷에서 다운받은 영상으로 쇼츠를 만듭니다. 위아래 검정 쇼츠 포맷이며 제목은 스티커 도형(검정 채우기) + 자동 캡션을 씁니다. 주의점: 특정인 비방 금지, 한쪽 성향으로 일관, 허위사실·자극적 내용 금지. [정치영상 만들기]
- **강아지 위로 vs 막장 드라마 컨셉**: 같은 노트의 앞부분이 반려동물 위로 채널([1-5](#1-5-내-채널-컨셉들))입니다.

### 3-5. 시니어 · 인생사연 · 심리학 채널
- **시니어 채널 소재**: 인생사연, 건강정보, 야담, 심리학, 북한 사연, 경제학, 한국사, 해외 감동 사연 [유튜브로 북한영상]
- **북한 영상**: 유튜브에서 "북한"으로 검색해 최근 조회수 좋은 영상을 참고합니다. 핵심은 모성애·가족애·자유의 소중함·통일 소망이고, 시니어 공감 포인트(부모 마음·고향 그리움·분단의 아픔) 2~3가지를 넣고 Claude에 "시니어 특화로 글을 써줘"라고 시킵니다. 휴대폰 촬영이 가능하며 20~30만 원대 PD들도 많이 쓴다고 합니다. 편집 방식과 스톡 영상 때문에 허위 콘텐츠가 될 수 있다는 점, 1년에 한 번씩 없어지는 채널이 많다는 점(4월)도 메모됨.
- **60대 이상 시니어 영상 제작 순서**: 잘 나가는 영상의 썸네일 캡처 → 캡처로 대본 만들기(유튜브 써머리) → 브루 → AI 목소리로 대본 붙여넣기 → 전문가 정면 이미지 → 플로우에서 영상 생성 → 브루에서 글자 200/고딕/한 줄 약 18자, 자동 클립 나누기, 무료 에셋(블루베리 검색)으로 사진 채우기 → 내보내기. 영상에 "AI 영상"임을 반드시 입력.
