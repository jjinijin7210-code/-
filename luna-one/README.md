# Luna One

기사·유튜브·글·스크린샷 하나를 인스타그램/틱톡/스레드/블로그/카드뉴스용 콘텐츠로 바꿔주는 독립 실행형 프로그램.
애니원(anyone-dashboard)과는 별도로 상용화 테스트를 위해 분리한 프로젝트 — 검증되면 나중에 애니원에 합칠 수 있음.

## 원본 (Luna와 함께 만든 시제품)
2026-07-25에 진희님이 Luna(다른 AI 툴)와 함께 만든 `Luna_One_2.0` 시제품의 화면/입력 방식을 그대로 가져왔고,
콘텐츠 생성 로직은 애니원에서 이미 검증된 방식(플랫폼 하나당 프롬프트 하나씩 나눠서 호출, Claude 사용)으로 새로 짰다.
시제품은 8개 플랫폼(유튜브 쇼츠/롱폼 포함) x 5개 언어를 한 프롬프트로 요청했는데, 응답이 커지면 잘리거나 파싱이
깨질 위험이 있어서(애니원에서 실제로 겪었던 문제) 플랫폼 x 언어 조합마다 따로 호출하도록 바꿨다.

## 이번 버전 범위 (2026-07-25 기준)
인스타그램 / 틱톡 / 스레드 / Google Blog / Naver Blog / 카드뉴스 — 이 6개만.
유튜브 쇼츠·롱폼 대본은 시제품엔 있었지만 이번 "간단한 상용화 테스트" 범위에서는 뺐다.

## 실행
1. `npm install`
2. `START_WINDOWS.bat`를 더블클릭하거나 `npm start`
3. 브라우저에서 `http://localhost:4174`

`.env.example`을 복사해서 `.env`로 만들고 `ANTHROPIC_API_KEY`를 넣으면 실제 생성이 된다 (없으면 데모 문구로 화면만
확인 가능). 카드뉴스 이미지는 사용자가 카드마다 "이미지 만들기" 버튼을 직접 눌러야 생성됨(자동 아님, 비용 통제
목적) — `OPENAI_API_KEY`가 있어야 작동.

## 아직 없는 것 (상용화하려면 필요)
- 회원가입/로그인, 결제, 사용량 제한 — 지금은 완전히 로그인 없는 단일 사용자용 로컬 도구
- 생성 결과 저장(DB) — 지금은 "전체 저장" 버튼으로 JSON 파일 다운로드만 가능, 새로고침하면 사라짐
- 실제 SNS 자동 발행 — 이 프로그램은 콘텐츠만 만들어주고, 게시는 사용자가 직접 복사해서 함 (자동 발행 아님)

## 원칙
- 원문을 그대로 복사하지 않고 공통 패턴만 재구성한다.
- 개인 경험인 것처럼 거짓 1인칭으로 단정하지 않는다.
- 가격/운영시간/교통편처럼 변할 수 있는 정보는 게시 전 최신 정보를 확인해야 한다는 걸 표시한다.
