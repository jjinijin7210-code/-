# 애니원(AnyOne) 직원 현황판 — 1단계 웹 대시보드

정적 웹 대시보드입니다. 빌드 없이 `index.html`을 브라우저로 열거나 정적 파일 서버로 서빙하면 됩니다.

## 구성
- `data.js` — 직원 명단(기획서 2장 기준 16개 역할)과 역할별 업무 프리셋
- `app.js` — 활동 로그 상태 관리, 직원 카드/활동 피드 렌더링
- `styles.css`, `index.html` — 화면

## 활동 로그 개념
- 자동화된 역할(대부분)은 `시작`/`완료` 액션이 발생할 때마다 활동 로그(`{ 직원, 작업, 시작시각, 완료시각, 상태 }`)를 기록합니다.
- 직원 카드는 해당 직원의 가장 최근 미완료 활동을 자동으로 보여줍니다. 없으면 `⚪ 대기 중`.
- "지금 하고 있는 일" 패널은 모든 시작/완료 이벤트를 시간순으로 보여주며 5초마다, 또는 액션 발생 즉시 갱신됩니다.
- 아직 자동화되지 않은 역할(예: 영상 제작 담당, 3단계 예정)은 기존처럼 클릭으로 상태를 순환(대기→검토중→통과)합니다.

## 2단계(자동화 백엔드) 연동 포인트
`window.AnyOneActivityLog.startActivity(employeeId, taskLabel)` / `.completeActivity(employeeId)` 를
실제 파이프라인(리서치/초안/번역/검수/발행/CS)에서 이벤트가 발생할 때 그대로 호출하면
대시보드에 자동으로 반영되도록 설계했습니다. 지금은 카드의 시작/완료 버튼이 같은 훅을 호출해
동작을 시뮬레이션합니다.

데이터는 `localStorage`에 저장되어 새로고침해도 유지됩니다.
